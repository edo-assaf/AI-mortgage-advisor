# Roots Off - Business Plan

## Executive Summary

**Product**: AI-powered JIRA root cause analyzer that automatically identifies bug patterns, extracts root causes, and generates actionable Epics/Stories to reduce bug volume by 20-40%.

**Technology**: Proprietary 5-phase pipeline (Ingestion -> Triage -> Deep Analysis -> Aggregation -> Reporting) using LangChain and Vector Search to analyze both JIRA tickets and source code.

**Business Model**: SaaS subscription via Atlassian Marketplace
- **Target Market**: Enterprise and mid-market software companies using JIRA
- **Pricing**: $99-$390/month (4 tiers + free trial)
- **Revenue Model**: Subscription-based with annual discounts
- **Go-To-Market**: Product-led growth, zero marketing spend, organic discovery

**Key Metrics (Year 1 Targets):**
- Phase 1: 5 customers (Month 1-3)
- Phase 2: 50 customers (Month 4-6)
- $8,525 MRR ($102,300 ARR) at Phase 2
- 84%+ net profit margin (Phase 2)
- < 5% monthly churn
- > 100% Net Revenue Retention
- $0 marketing spend
- Infinite ROI (near-zero customer acquisition cost)

**Competitive Advantage:**
- **Deep Code Analysis**: Analyzes actual source code alongside JIRA tickets (using LangChain).
- **Semantic Clustering**: Uses Vector DB to find hidden patterns across thousands of tickets.
- **Cost-Efficient Triage**: Proprietary LLM triage filters out non-bug tickets (duplicates, "works as designed", configuration issues) before deep analysis.
- **Actionable Results**: Only JIRA app that auto-generates Epics/Stories from root cause analysis.

### 7. Tools & Infrastructure (Minimal Cost)

#### Technical Stack (Production)
- **Frontend**: Atlassian Forge
- **Backend**: Python Microservices (7 services via ECS Fargate)
- **Data Store**: Redis (Queue/Cache), S3 (Raw Data), PostgreSQL + pgvector
- **LLM Provider**: GPT 5.1 nano
  - **Pricing**: Input $0.05/1M tokens, Output $0.40/1M tokens
  - **Per Ticket Cost**: ~$0.002 (with 20% buffer)

#### AWS Infrastructure (Production-Ready, Cost-Optimized)

> Resource allocations validated via load testing. See [Load Testing Guide](../LOAD_TESTING.md) for methodology.

**Fixed Costs (Required for Monitoring/Observability):**
- **Ops Server** (t3.xlarge): Runs PostHog, Langfuse, Grafana, Prometheus, Vault (~$121/mo)
  - Langfuse (LLM cost tracking): 2GB server + 2GB worker + 4GB ClickHouse
  - Monitoring requires ~9GB RAM; cannot downgrade from t3.xlarge

**Variable Costs (Scale with Customer Growth):**
- **ECS Fargate**: Application workers (API, ingestion, analysis, aggregation)
- **RDS PostgreSQL**: Scan metadata, tenant data, licensing
- **ElastiCache Redis**: Job queues, caching
- **S3**: Raw data, HTML reports
- **NAT + ALB**: Networking

**Phase 1 (5 customers):** ~$296/month
**Phase 2 (50 customers):** ~$599/month

Infrastructure scales in 3 stages (15, 30, 50 customers) to match demand.

#### Infrastructure Scale-Up Plan

**Phase 1 → Phase 2 Cost Evolution:**

| Milestone | Customers | Monthly Infra | Key Changes |
|-----------|-----------|---------------|-------------|
| **Launch** | 5 | $285 | Minimal baseline, single-AZ |
| **Trigger 1** | 15 | $355 | Enable RDS Multi-AZ, Redis replica |
| **Trigger 2** | 30 | $480 | Scale RDS instance, add NAT Gateway |
| **Phase 2** | 50 | $599 | Full production config, HA everywhere |

**Cost Growth is Predictable:**
- Infrastructure cost/customer: $57.00 (Phase 1) → $11.98 (Phase 2)
- Monitoring fixed cost amortizes across customer base
- 80%+ of infrastructure scales automatically via ECS auto-scaling
